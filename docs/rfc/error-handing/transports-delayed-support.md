Delayed Re-delivery Across Transports

The error handler actor needs to send a message back to the original actor's queue with a delay. Different transports have wildly
different support for this:
┌───────────────────┬───────────────────────────────────────────────────────────────────────────────────┬──────────────────┐
│     Transport     │                              Native Delay Mechanism                               │    Max Delay     │
├───────────────────┼───────────────────────────────────────────────────────────────────────────────────┼──────────────────┤
│ SQS               │ DelaySeconds on SendMessage (up to 15 min) or ChangeMessageVisibility (up to 12h) │ 12h              │
├───────────────────┼───────────────────────────────────────────────────────────────────────────────────┼──────────────────┤
│ RabbitMQ          │ x-delayed-message plugin or TTL + dead-letter exchange                            │ Plugin-dependent │
├───────────────────┼───────────────────────────────────────────────────────────────────────────────────┼──────────────────┤
│ Google Pub/Sub    │ No native delay                                                                   │ N/A              │
├───────────────────┼───────────────────────────────────────────────────────────────────────────────────┼──────────────────┤
│ NATS JetStream    │ NakWithDelay                                                                      │ Unlimited        │
├───────────────────┼───────────────────────────────────────────────────────────────────────────────────┼──────────────────┤
│ Redis Streams     │ No native delay                                                                   │ N/A              │
├───────────────────┼───────────────────────────────────────────────────────────────────────────────────┼──────────────────┤
│ Azure Service Bus │ ScheduledEnqueueTimeUtc                                                           │ Unlimited        │
├───────────────────┼───────────────────────────────────────────────────────────────────────────────────┼──────────────────┤
│ Kafka             │ No native delay                                                                   │ N/A              │
└───────────────────┴───────────────────────────────────────────────────────────────────────────────────┴──────────────────┘
