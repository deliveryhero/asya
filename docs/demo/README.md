# KubeCon Demo: Evaluator-Optimizer on Asya

Text generation flow: **generator** writes a draft, **evaluator** scores it,
loop until quality threshold is met, then **polisher** finalizes.

## Prerequisites

- Python 3.13+, [uv](https://docs.astral.sh/uv/)
- GCP project with Vertex AI API enabled
- Service account key with `roles/aiplatform.user`

## Setup

```bash
cd docs/demo
uv sync
uv pip install -e .
source .venv/bin/activate
```

Install asya-lab from GitHub
```
uv pip install git+https://github.com/deliveryhero/asya.git#subdirectory=src/asya-lab
uv run asya --version
```

### GCP credentials

```bash
export GCP_PROJECT=<your-gcp-project>

# Create service account (once)
gcloud iam service-accounts create asya-demo \
  --display-name="Asya KubeCon Demo" \
  --project=$GCP_PROJECT

gcloud projects add-iam-policy-binding $GCP_PROJECT \
  --member="serviceAccount:asya-demo@${GCP_PROJECT}.iam.gserviceaccount.com" \
  --role="roles/aiplatform.user"

# Create SA key:
gcloud iam service-accounts keys create /tmp/asya-demo-sa.json \
  --iam-account=asya-demo@${GCP_PROJECT}.iam.gserviceaccount.com

export GOOGLE_APPLICATION_CREDENTIALS=/tmp/asya-demo-sa.json
export VERTEXAI_PROJECT=$GCP_PROJECT
export VERTEXAI_LOCATION=us-central1
```

## Step 1: Run flow locally

The flow is a pure async Python function. `generator`, `evaluator`, and
`polisher` are unresolved names — in production, Asya resolves them to actor
queues. Locally, we bind them to the real handler functions:

```python
uv run python -c '
import asyncio
from demo_flows.text_improver import text_improver
state = {"task": "Write a haiku about message queues"}
asyncio.run(text_improver(state))
'
```

The flow runs as a single process — sequential calls, no queues, no actors.
Same code, same results.

## Step 2: Compile to actor graph

```bash
asya compile src/demo_flows/text_improver.py --plot
```

Output paths are configured in `.asya/config.yaml`:
- `src/demo_actors/compiled/text_improver/` — router Python code + `flow.svg`
- `.asya/manifests/text-improver/base/` — AsyncActor CRDs + router ConfigMap

Open `src/demo_actors/compiled/text_improver/flow.svg` to see the generated actor graph with loop-back edges.

## Step 3: Deploy to Kind cluster

Load GCP credentials as K8s secret:
```bash
kubectl create namespace asya-demo || true
kubectl create secret generic vertex-ai-creds \
  --namespace=asya-demo \
  --from-file=sa-key.json=/tmp/asya-demo-sa.json \
  --from-literal=project-id=$GCP_PROJECT
```

Apply flavors (platform engineer's config):
```bash
kubectl apply -f .asya/manifests/flavors/
```

Build and load handler image:
```bash
docker build -t asya-demo:latest .
kind load docker-image asya-demo:latest --name asya-quickstart
```


Deploy and verify:
```bash
# Deploy actors
asya k apply src/demo_flows/text_improver.py

# Verify
kubectl -n asya-demo get asyncactors

# Send a message
asya k send start-text-improver '{"task": "Write a limerick about message queues"}'

# Watch it flow
asya k logs --follow
```

## Project structure

```
docs/demo/
├── Dockerfile                              # actor image (litellm + demo code)
├── pyproject.toml
├── uv.lock
├── .asya/
│   ├── config.yaml                         # build entry, compiler paths, template vars
│   ├── config.compiler.rules.yaml          # flow compiler rules
│   ├── compiler/templates/                 # AsyncActor + ConfigMap + kustomization templates
│   │   ├── actor.yaml
│   │   ├── router.yaml
│   │   ├── configmap_routers.yaml
│   │   └── kustomization.yaml
│   └── manifests/
│       ├── flavors/                        # platform config (GCP credentials, LLM retry)
│       │   ├── vertex-ai.yaml
│       │   └── llm-resilient.yaml
│       └── text-improver/                  # ← generated by asya compile
│           ├── base/                       # fully regenerated on each compile
│           └── common/                     # user patches (preserved across recompiles)
├── manifests/                              # hand-authored actor specs (flavors, scaling)
│   ├── generator.yaml
│   ├── evaluator.yaml
│   └── polisher.yaml
└── src/
    ├── demo_flows/
    │   └── text_improver.py                # the flow (compiles to actor graph)
    └── demo_actors/
        ├── generator.py                    # Gemini: generate/revise draft
        ├── evaluator.py                    # Gemini: score + feedback
        ├── polisher.py                     # Gemini: final polish
        └── compiled/                       # ← generated by asya compile
            └── text_improver/
                ├── routers.py
                ├── flow.dot
                └── flow.svg
```
