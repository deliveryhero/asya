Add async handler support to asya_runtime.py. When the loaded handler is an async function (coroutine), execute it with asyncio.run().

## Changes

### asya_runtime.py
- Import asyncio, inspect
- After loading handler, detect if it's a coroutine function: inspect.iscoroutinefunction(handler)
- If async: result = asyncio.run(handler(payload))
- If sync: result = handler(payload) (current behavior)

## Why
Async handlers are needed for:
- Calling async LLM APIs (e.g., gemini.generate_content_async)
- Awaiting HTTP clients (aiohttp, httpx)
- Foundation for AsyncGenerator streaming handlers

## Constraints
- asya_runtime.py must remain Python 3.7+ compatible (use typing.Dict, not dict)
- No new dependencies (asyncio is stdlib)
- Must work with both payload and envelope handler modes

## Test Plan
- Unit test: async handler returns correct result
- Unit test: sync handler still works (backward compatibility)
- Component test: async handler in Docker compose with sidecar
