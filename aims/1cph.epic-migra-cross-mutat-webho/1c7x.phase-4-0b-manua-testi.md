Manually validate the new Crossplane + Webhook architecture by following the quickstart documentation.

## Tasks

1. Follow quickstart docs in a fresh Kind cluster
2. Validate each step works as documented:
   - Crossplane installation
   - Provider installation and health
   - ProviderConfig creation
   - Webhook deployment
   - XRD and Composition deployment
3. Create test AsyncActor and verify:
   - SQS queue created in LocalStack
   - KEDA ScaledObject created
   - Deployment created with correct labels
   - Pods get sidecar injected
4. Send test messages and verify processing:
   - Message consumed from queue
   - Handler executes correctly
   - Result routed to next actor or happy-end
5. Test scaling:
   - KEDA scales up with queue depth
   - KEDA scales to zero when idle
6. Document any issues found and fix docs/code

## Acceptance Criteria

- Complete end-to-end flow works manually
- All issues discovered are fixed or documented
- Quickstart docs are validated as accurate
- Ready for E2E test automation
