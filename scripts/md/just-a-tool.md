git-aint is a small CLI that wraps markdown files and git.
That is the whole pitch.

It is not a project management platform. It is not trying to replace
anything. It does not have a dashboard, a web UI, or a roadmap for
adding one. It will never ask you to upgrade to a paid tier.

The markdown files are the source of truth. Git handles sync and
history. You handle the rest -- deciding what matters, what to
work on next, and when something is done.

A tool, not a product. Use it, ignore it, fork it. It is just files.
