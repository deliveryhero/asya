## Summary

Extend the asya-crew Helm chart with built-in persistence flavors so that enabling
checkpointing is a one-liner in values:

```yaml
# values.yaml
crew:
  persistence:
    backend: s3
    config:
      bucket: my-checkpoints
      endpoint: ""  # omit for AWS, set for MinIO
```

The chart auto-creates the necessary EnvironmentConfig flavor and references it
in crew actors' `spec.flavors` list, wiring stateProxy with the correct connector
image and ASYA_PERSISTENCE_MOUNT.

## What This Enables

Users no longer need to manually:
1. Create a stateProxy EnvironmentConfig flavor
2. Wire connector image, env vars, and mount path
3. Add the flavor to each crew actor's flavors list

Instead: `persistence.backend: s3` → chart creates everything.

## Design

### Flavor EnvironmentConfig (generated by chart)

```yaml
apiVersion: apiextensions.crossplane.io/v1alpha1
kind: EnvironmentConfig
metadata:
  name: asya-persistence-s3
  labels:
    asya.sh/flavor: persistence-s3
data:
  persistence-s3:
    stateProxy:
      - name: checkpoints
        mount:
          path: /state/checkpoints
        connector:
          image: ghcr.io/deliveryhero/asya-state-proxy-s3-buffered-lww:v1.0.0
          env:
            - name: STATE_BUCKET
              value: "{{ .Values.persistence.config.bucket }}"
    env:
      - name: ASYA_PERSISTENCE_MOUNT
        value: /state/checkpoints
```

### Chart Values Schema

```yaml
persistence:
  enabled: false
  backend: ""  # s3 | gcs | postgresql (only s3 initially)
  config: {}   # backend-specific config (bucket, endpoint, etc.)
```

### Actor Integration

When `persistence.enabled: true`, the chart:
1. Creates the EnvironmentConfig (template: `templates/persistence-flavor.yaml`)
2. Adds the flavor name to x-sink and x-sump AsyncActor `spec.flavors[]`
3. Sets `ASYA_PERSISTENCE_MOUNT` on crew actors via the flavor env injection

x-sink gets `/state/checkpoints/results`, x-sump gets `/state/checkpoints/errors`
(or configurable via `persistence.resultsMountSuffix` / `persistence.errorsMountSuffix`).

## Deliverables

1. New Helm template: `templates/persistence-flavor.yaml` (EnvironmentConfig)
2. Updated `values.yaml` with `persistence:` section
3. Updated `templates/sink.yaml` and `templates/sump.yaml` to include flavor ref
4. Unit tests: `helm template` assertions for generated EnvironmentConfig
5. Integration test update: wire state proxy connector in Docker Compose for crew actors
