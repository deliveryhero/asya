Allow local variables to cross await boundaries by automatically serializing them into the payload.

## Problem
Currently, local variables are lost at CPS split points:

```python
async def flow(state: dict) -> dict:
    var1 = compute()              # local variable
    state = await actor_a(state)  # await split — var1 is lost!
    print(var1)                   # ERROR: var1 doesn't exist in continuation router
    return state
```

The current compiler (asya-cv4g) detects this and emits an error, forcing the user to manually save to payload.

## Solution: Auto-Serialization
The compiler automatically injects save/restore around await boundaries:

Before await:
```python
state["__local__var1"] = var1
```

After await (in continuation router):
```python
var1 = state.pop("__local__var1")
```

## Implementation

### Static Analysis (extend asya-cv4g)
1. For each AwaitCall, compute the set of live local variables
2. A variable is "live across boundary" if assigned before the await AND referenced after
3. For each live variable, inject Mutation nodes: save before await, restore after

### Code Generation
- Generated save mutations: `state["__local__var1"] = var1`
- Generated restore mutations: `var1 = state.pop("__local__var1")`
- Prefix `__local__` prevents collision with user payload fields
- Clean up: pop() removes temporary keys from payload after restoring

### Serialization Constraints
- Only JSON-serializable types can be auto-serialized (str, int, float, bool, list, dict, None)
- Non-serializable types (objects, generators) -> compiler error with suggestion to refactor
- Type detection via type hints or runtime isinstance check

## Enables
- for loop variables: `for tc in state["tool_calls"]: ...`
- Intermediate computations: `result = compute(state); state = await next(state); use(result)`
- Multi-assign patterns: `a, b = state["x"], state["y"]; state = await process(state)`

## Test Cases
```python
# Simple local variable
async def flow(state: dict) -> dict:
    prefix = "hello"
    state = await actor(state)
    state["greeting"] = f"{prefix} {state['name']}"
    return state

# For loop variable
async def flow(state: dict) -> dict:
    for item in state["items"]:
        state["current_item"] = item
        state = await process(state)
    return state
```
